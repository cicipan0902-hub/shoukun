# V0.3.1 体验修复

本轮修复用户实际试玩发现的四个问题，原剧情、人物 ID、revision 与存档结构保持不变。

1. **聊天可以输入**：校园微信私聊换成真实文本输入框，不再只弹出模拟键盘。自由文字作为“你的自由留言”保存在本浏览器；未配置 AI 时不会伪造角色回复。切换“日常留言”也可发送并保存。原有 AI 接口仍保留，配置成功后恢复“日常私聊 · AI”。
2. **输入可以选择剧情回复**：主线回复选项显示在聊天下方；直接点击即可。也可输入与某个当前选项相同的句子发送，按同一个选择节点推进，不重复生成消息。任意其他留言不会偷偷改变剧情。
3. **下一步可见**：聊天下方显示“继续对话”、等待提示、回复选项，或去朋友圈/备忘录的具体路径。手机右下角“剧情指引”可随时查看下一步并打开相关 App。继续按钮只阅读已经可见且可触发的下一条消息，不解锁未来消息、不跳过选项。
4. **朋友圈排版与头像**：正文按钮不再继承全局 inline-flex，名字、正文、日期分行排列且左对齐；头像去除误继承的 8px 上边距，图片完整覆盖头像框。手机 390px 宽度下验证：页面宽度390，无横向溢出；头像和图片边界一致、顶部间距0、原图加载成功。

当前预览沿用电脑 `http://127.0.0.1:4187/`，同一 Wi-Fi 手机 `http://10.47.131.94:4187/`。更新后如仍看到旧界面，等几秒再刷新一次，让离线缓存更新；不需要清除存档。检查底部是否出现真实输入框和“继续对话”可判断是否已更新。

源码修改集中在 `src/personalization/`、`src/AppSkins.tsx`、`src/Phone.tsx`、`src/media/AvatarImage.tsx` 与 `src/media/media.css`。没有修改故事文本或后续关系设定。`chapterGuide` 按当前运行状态计算提示，不把未来台词写进提示。

验证记录：类型检查、lint、65 项单元测试、18 条剧情回放及 author:build 通过。新增引导测试遍历全部18条路线，检查每个继续目标确为当前下一条、回复和跨 App 目标正确。另通过实际浏览器验证真实输入、自由留言显示、输入原句选择主线回复、按钮推进、朋友圈排版与头像尺寸。刷新后已确认自由留言与剧情阶段恢复；使用继续按钮和原句输入选项从头走通到第一章结尾，并验证剧情指引弹层可跳转到备忘录。本次没有声称 Chrome 自动端到端测试通过，环境此前在 Chrome 启动阶段受限。

浏览器存档仍仅限本机本浏览器；自由留言不会自动获得 AI 回复。原有 WhatsApp、其他作品和作者添加消息入口保留。没有推送或公开部署。
