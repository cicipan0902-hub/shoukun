## 启动

在当前项目目录执行 npm run author:dev 启动开发预览；更新当前网页版用 npm run author:build，随后 npm run preview:lan。后者默认4173端口；本次已有服务继续用4187端口，无需另开。

若需要同样的4187端口且当前没有服务，可执行 npm run preview:lan -- --port 4187。电脑 http://127.0.0.1:4187/；手机与电脑同一Wi-Fi后使用电脑局域网地址。刷新并继续原存档，离线缓存未更新时再刷新一次，不需要重新开始。
