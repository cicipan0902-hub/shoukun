# 校园群像手机 V0.3 ·《好天气》交付说明

## 已完成的修改

默认入口已切换为第一章《好天气》。仍使用现有 Phone、微信/朋友圈/备忘录界面、事件引擎、选择节点和浏览器自动存档；没有新增剧情引擎或升级依赖。

- 五个人物头像统一用于聊天列表、聊天气泡、通讯录、朋友圈及微信个人页。
- 群头像已登记，旧演示的群头像机制通过真实文件导入验证；第一章不向玩家展示四人群。
- 纯文字朋友圈：15 条初始显示（每人三条），9 条未来动态隐藏，另 1 条张泽禹私密内容仅存作者配置。均没有新图片绑定。
- 三处交互选择：哥哥散场回复 2 项、评价学长 3 项、回复左航 3 项，共 18 种组合。选择分别写入 `ch01.greeting`、`ch01.expression`、`ch01.zuoReply`，不改变好感度。
- 消息通过阅读事件逐步解锁；对方回复部分等待 0.6–1 秒。点击最新气泡推进，不会自动把整段未来消息展示出来。
- 哥哥聊天完成且读过朱志鑫的天气动态，才解锁女主日记。提前浏览动态也不会卡住。
- 阅读日记后收到左航消息；完成左航选择并阅读结尾备忘录，显示章节完成提示并自动保存。
- 复用现有结局提示界面显示第一章完成；没有第二章，也没有朱志鑫主动私聊。
- 可选剧情日标签让锁屏显示“开学第一天”。技术底层的手机日期默认值仍是占位，不是正式年份或时间线。
- 修复群头像原先受普通元数据 2000 字符上限阻挡的问题：只有安全内嵌群头像允许更长内容，其他元数据限制保留。
- 原格式会重复内嵌头像，当前作品 JSON 约 11.2 MB；离线缓存单文件上限调整为 16 MiB，构建通过。

## 试玩路径

1. 设定昵称，点击“让故事发生”，解锁手机。
2. 微信 → 张泽禹 → 点击“散场了没”，选择第一句回复。
3. 轻触最新消息推进；对方回复偶有短暂等待。
4. 在“怎么了”之后，从三句评价中选择一句，收到对应调侃，然后汇合。
5. 按通知进入微信 → 发现 → 朋友圈，点开朱志鑫的“今天的天不错。”。
6. 返回桌面 → 备忘录 → 阅读《开学第一天》。
7. 返回微信 → 左航 → 继续对话，选择回复并阅读他的回应。
8. 备忘录 → 阅读《好像也没那么无聊》，出现第一章完成提示。
9. 刷新后点击“继续…的故事”，解锁手机，可恢复通关状态。

可先看备忘录中的《好天气 · 试玩指引》。15 条朋友圈都可以随时浏览，预设评论中的女主姓名会替换为玩家昵称；点赞沿用现有本地保存。其他动态不触发后续成长剧情。体验时长取决于阅读速度，本轮没有为了凑足 5–10 分钟加入长等待。

## 本地预览与手机访问

在项目目录执行：

```sh
npm run author:dev
```

作者开发环境包含原有调试面板。玩家版本：

```sh
npm run author:build
PORT=4187 npm run campus:serve
```

本轮已启动玩家版本：电脑打开 <http://127.0.0.1:4187/>，同一 Wi-Fi 的手机打开 <http://10.47.131.94:4187/>。两地址均已取得 HTTP 200。更新构建后若仍显示旧画面，等离线缓存更新后再刷新一次，无需清空存档。电脑必须开机且服务保持运行；换网络后电脑 IP 可能变化。手机不要用 127.0.0.1 访问电脑，也不要双击 index.html 作为部署方式。

如需单独检查保留的旧演示：

```sh
CAMPUS_PROJECT=stories/foundation/project-demo.json npm run author:check
```

此命令选择旧项目进行检查；日常使用默认命令继续《好天气》。不要手动改 `work/campus/story.json`、public/work.json 或 dist。

## 当前限制和后续补充

- AI 仍未配置，剧情选项可玩，不能自由获得模型回复。
- 存档保存在当前浏览器，不跨设备同步；新章使用独立作品 ID 保留原演示存档，未自动迁移或清空旧数据。
- 作者私密条目未编译。其余标为 hidden 的动态只是游戏隐藏内容，静态文件仍包含文本，不是安全保密机制。
- 现有内嵌素材格式导致重复头像和约 11.2 MB 的作品文件，首次手机加载可能偏慢。未来素材大量增加时再考虑资源去重，未在这轮重构。
- 群头像已准备，当前章节按剧情规则不开放四人群；没有给女主伪造群成员身份。
- 朋友圈目前使用“日常”标签、聊天使用“开学第一天”，没有虚构生日和正式年份。手机系统/日历仍保留原框架技术日期占位，不能当作故事正史。
- 原 UI 的通知浮层短暂出现时可能覆盖顶部返回位置，可等提示消失或从底部返回桌面继续。
- 浏览器自动测试受环境阻挡；未声称手机实机或离线断网验收完成。
