# V0.4.1 朋友圈权限与剧情入口修复

- 招募动态显示《文化节招募》标题，新解锁的动态排在旧动态前面。聊天底部新增“去朋友圈查看”；浮动剧情指引也能直达朋友圈，聊天指引能直达目标聊天。
- 未加好友时隐藏该角色本人发布的朋友圈，好友通过后按原解锁状态显示。保留共同群聊及好友转发/评论中的间接交集。
- 原先15条初始动态与素材仍在数据中。新增张泽禹《转发：今天的天不错》，用于第一章跨App触发；新存档初始能看到自己、哥哥、左航各3条及哥哥转发，共10条。
- 原天气动态的触发节点保留，兼容以前读过它的存档；不清理、重置或修改玩家好友状态。
- 现有旧存档如果曾正式解锁好友，会继续保留该好友关系，不能为隐藏动态而擅自取消好友。

验证：author:check、foundation:validate、foundation:test、typecheck、lint、npm test、author:build 均通过。单元测试14个文件72项；故事路径82条。测试覆盖非好友朋友圈隐藏、加好友后可见、招募跨App解锁、旧天气阅读存档兼容、分支与存档恢复。

本次仅修改本地项目，未推送或发布。电脑预览使用现有4187端口；手机需连接同一Wi-Fi后使用电脑局域网地址。

页面实测使用 localhost:4187 的独立“试玩检查”存档，未重置玩家存档：第一章三次选择→哥哥转发动态→备忘录→左航→通关；第二章哥哥选择→聊天底部直达朋友圈→可见《文化节招募》标题→点击解锁相册，剧情指引更新为“查看保存的资料”。截图见 outputs/V0.4.1-文化节招募可见.png。
