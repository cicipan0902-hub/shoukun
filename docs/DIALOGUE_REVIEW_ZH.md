# 本地微信台词审阅

打开项目中的“打开台词审阅.command”，或在项目终端运行 `npm run author:review`。
访问 http://127.0.0.1:4191/ 。电脑须运行工具；公网游戏没有这个入口。

1. 选章节、人物，查看台词及前后上下文。所有分支都会列出，分支标签说明所属选项；相邻卡片不一定属于同一条试玩路径。
2. 直接编辑文字，原文会出现在下方。可以标“待润色”“已审阅”，筛选后集中处理。内容菜单还能切换备忘录。
3. 草稿自动存于当前浏览器；“导出草稿”另存 JSON，换浏览器可导入。草稿和审阅标记不属于玩家存档。浏览器无法存储时会提示导出。
4. 点“保存到剧情文件”，确认后只写回文字。文件已被别处修改时拒绝覆盖，请先导出草稿，再重新读取、核对。
5. 保存后运行 `npm run author:build`，重启/刷新本地玩家预览，检查实际接话和节奏。审阅页保存不会自动重建，也不会自动发布。
6. 确认本地试玩后，再提交、推送 main，Cloudflare 才会自动更新公网。

备份位于项目 `work/dialogue-review-backups/时间戳/`，已排除 Git 和玩家发布包。需要恢复时关闭审阅页，将备份文件复制回其原来的 `stories/foundation/` 路径；先保留当前文件，避免盖掉后续修改。

数据来自当前 project.json 指定的源文件、扩展和 interactions.json，不编辑 work/campus、public、dist 等生成物。支持微信消息 body、flow 选项 text、第一章事件选项 label、notes 正文，以及明确署名的朋友圈正文/标题/评论；不修改剧情条件、延迟、ID、媒体引用。第一章菜单文字和实际气泡是两个独立字段，页面会提示，必要时分别修改。现场文档仅提取作者显式归属并限定引号边界的单句，不会替换整段旁白。当前归属配置在本地 docs/author-only/characters/zhuzhixin-review-targets.json。没有明确归属的现场台词、动态生成的亲属卡消息池仍不在工具范围。保存采用页内两次点击确认，避免浏览器原生弹窗阻塞。

工具仅绑定 127.0.0.1；无外部请求、无新增依赖。改用其他端口可设置 REVIEW_PORT。不要把此工具作为公网服务运行。
